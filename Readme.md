# Hotel Booking Website

A responsive and modern Hotel Booking Website built using HTML, CSS, and JavaScript. This project allows users to explore hotel rooms, view hotel details, and make booking requests through an attractive user interface.

## Features

- Responsive design for all devices
- Modern and user-friendly interface
- Hotel room listings
- Hotel details section
- Booking form
- Smooth navigation
- Attractive animations and styling

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
hotel-booking/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## Installation

1. Clone the repository

```bash
git clone https://github.com/Prashant6636/hotel-booking.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

## Usage

- Browse available hotel rooms.
- View hotel information and amenities.
- Fill out the booking form.
- Submit booking details.
